`components/board/src/touch_decode.*` and `board_touch.c` derive the packet layout and the reset and read sequence from `esp_lcd_touch_cst9217`, modified to validate every packet and map points to the display orientation. The mirror-then-swap order follows `esp_lcd_touch`.

## Previous Desk Assistant firmware (V4)

`components/connectivity/src/wifi_list.*` and `wifi_select.*` adapt the saved-network list and the station selection policy of the author's previous firmware, rewritten as modules with a setup pause and a wake time.

`components/bridge/src/bridge_http.c` and `bridge_tls.*` adapt the finite HTTP gate and deadline-bounded TLS transport from `main/app_http_gate.c` and `main/app_events.c` of the same revision.

`components/bridge/src/bridge_assistant.c` adapts the strict six-field assistant response codec from `main/assistant_codec.c`.

`components/bridge/src/bridge_events.c` adapts the strict event response codec from `main/event_codec.c`.

`components/bridge/src/bridge_json.*` and `bridge_time.*` hold the JSON guard, the exact-field check and the UTC timestamp validation extracted from that codec.

`components/bridge/src/bridge_snooze.c` adapts the Snooze request and response codec from `main/snooze_codec.c`.

`components/features/notifications/src/notification_tones.c` adapts the RAM tone saturation policy from `main/notification_tones.c`.

`components/bridge/src/bridge_sse.*` adapts the incremental event stream state, framing and reconnection timing, with strict JSON validation and expanded per-frame budgets.

`components/features/recording/src/recording_clip.*` adapts the temporary audio clip with the synthesized WAV header from `main/audio_clip.c`, clearing only the written range after each attempt.

`components/bridge/src/bridge_stream.c` adapts the authenticated SSE transport, header checks and bounded opening from `main/app_events.c` of the same revision.
